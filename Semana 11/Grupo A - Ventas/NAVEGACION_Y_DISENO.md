# Mis nueve pantallas UIKit

Organicé el flujo funcional con `SceneDelegate`, `UINavigationController` para el ingreso y `UITabBarController` para las opciones por rol. Mis pantallas A1–A9 están implementadas con UIKit programático en los archivos `.swift` y sus controladores. También agregué `DISEÑO_UKIT_9_PANTALLAS.storyboard` con un navegador principal y las nueve maquetas que puedo inspeccionar en Interface Builder. El Storyboard es una referencia visual: la ejecución real utiliza los controladores Swift y no este archivo. No cuento el navegador principal como una décima pantalla.

Aún debo comprobar en mi Mac que el proyecto abre, compila y que cada interacción funciona en el simulador.
