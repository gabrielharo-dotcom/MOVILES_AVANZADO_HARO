# Ventas Tecsup — Grupo A, Semana 11

Proyecto de Gabriel Haro. App iOS UIKit + Core Data, sin SwiftUI. Incluye 4 entidades, 9 pantallas y roles Vendedor y Supervisor.

Abrir VentasTecsup.xcodeproj en Xcode 26.3; elegir el esquema VentasTecsup y ejecutar con Cmd+B/Cmd+R. El archivo de proyecto se reconstruyó usando una plantilla Xcode 26.3 del mismo repositorio tras el cierre reportado por el estudiante. **La apertura, compilación y ejecución deben verificarse en macOS.**

Pantallas: A1 Ingreso.swift; A2 Registro.swift; A3 Productos.swift; A4 Clientes.swift; A5 NuevaVenta.swift; A6 y A7 Historial.swift; A8 alerta de anulación en Historial.swift; A9 Resumen.swift. Extra: Cuenta en App.swift. El diseño UIKit es programático y usa Auto Layout, no Storyboard. Consultar PRUEBAS.md.

El profesor indicó que para la tarea domiciliaria no se requiere visto bueno previo del expediente.
