# Ventas Tecsup — Grupo A | Semana 11

Soy Gabriel Haro y presento mi aplicación iOS de ventas desarrollada con UIKit y Core Data. Organicé el proyecto en nueve pantallas del caso A y una vista adicional de Cuenta. Usé cuatro entidades (Usuario, Producto, Cliente y Venta), con roles de Vendedor y Supervisor.

## Cómo lo abro

Abro `VentasTecsup.xcodeproj` en Xcode 26.3, selecciono el esquema VentasTecsup y un iPhone simulado, compilo con Cmd+B y ejecuto con Cmd+R. Reorganicé la configuración del proyecto después del cierre de Xcode reportado; todavía debo comprobar la compilación y el funcionamiento en mi Mac.

## Pantallas

A1 Ingreso, A2 Registro, A3 Productos, A4 Clientes, A5 Nueva venta, A6 Mis ventas, A7 Ventas del equipo, A8 Anulación y A9 Resumen. También incluyo Cuenta. Diseñé la interfaz con UIKit programático y Auto Layout, no SwiftUI ni Storyboard.

Separé las etapas en `main`, `manual` y `ai-assisted`. Uso `main` para la entrega propuesta, `manual` para el prototipo base y `ai-assisted` para las mejoras con IA. Según la indicación del profesor, no necesito visto bueno previo del expediente por tratarse de una tarea domiciliaria.
