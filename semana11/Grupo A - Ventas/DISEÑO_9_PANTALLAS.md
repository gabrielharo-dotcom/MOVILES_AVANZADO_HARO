# Diseño de mis nueve pantallas UIKit

Construí la interfaz con UIKit programático: `UIViewController`, `UITableView`, `UITabBarController`, `UIAlertController` y Auto Layout.

| Pantalla | Cómo la implementé |
|---|---|
| A1 Ingreso | Uso `Ingreso.swift` con usuario y contraseña. |
| A2 Registro | Uso `Registro.swift` para crear cuentas y seleccionar el rol. |
| A3 Productos | Uso `Productos.swift` para consultar y gestionar productos. |
| A4 Clientes | Uso `Clientes.swift` para consultar y gestionar clientes. |
| A5 Nueva venta | Uso `NuevaVenta.swift` para seleccionar cliente, producto, cantidad y calcular importes. |
| A6 Mis ventas | Uso `Historial.swift` para consultar mis ventas. |
| A7 Ventas del equipo | Uso `Historial.swift` con los filtros del Supervisor. |
| A8 Anulación | Uso una alerta UIKit en `Historial.swift` para exigir un motivo. |
| A9 Resumen | Uso `Resumen.swift` para los indicadores del Supervisor. |

También añadí una pantalla Cuenta desde `App.swift`. Todavía debo tomar capturas reales del simulador para comprobar que el aspecto coincide con mi diseño.
