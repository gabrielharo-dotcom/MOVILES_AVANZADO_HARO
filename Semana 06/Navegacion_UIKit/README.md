# Navegación entre pantallas

Proyecto UIKit con Storyboard para la primera parte del laboratorio 06.

Un `UINavigationController` inicia en **PANTALLA 01**. El botón de la barra **A Pantalla 2** realiza un segue `Show` hacia **PANTALLA 02**; la barra ofrece el regreso a la primera pantalla.

Abrir `Navegacion_UIKit.xcodeproj` en Xcode.

El icono universal se preparó a partir del [logo de Tecsup](https://www.tecsup.edu.pe/wp-content/uploads/2024/06/logo-tecsup.jpg) para las resoluciones de iPhone, iPad y App Store.
